# Power BI Dashboard

The project contains two interactive Power BI pages:

## Executive Overview

- Total Orders
- Total Units
- Total Sales
- Total Profit
- Average Cycle Time
- SLA Compliance
- Delayed Orders by Bottleneck Stage
- Delay Rate by Shipping Mode
- Delay Rate by Shift
- Delay Rate by Warehouse
- Warehouse, Shift, Shipping Mode, Order Priority and Customer Segment filters

## Warehouse Operations

- Total Orders
- Delayed Orders
- Overall Delay Rate
- Average Cycle Time
- Delayed Orders by Bottleneck Stage
- Warehouse Delay Rate
- Warehouse × Bottleneck operational matrix
- Shift × Bottleneck operational matrix
- Average Cycle Time by Bottleneck Stage

The `.pbix` dashboard file should be uploaded to this folder from Power BI Desktop.
